# Performance Testing Project - E-commerce Platform

## Overview

This repository contains the design, execution and analysis of performance tests performed using Apache JMeter.

The objective of the project was to evaluate the behavior of an e-commerce platform under load conditions, measuring response times, throughput, and system stability.

## Tools Used

* Apache JMeter
* CSV Data Sets
* HTML Reports
* Performance Monitoring Tools

## Test Scenarios

### Login Scenario

Simulation of concurrent user authentication requests using parameterized test data.

### Purchase Scenario

Simulation of purchase operations with multiple virtual users executing transactions simultaneously.

## Repository Structure

* `Proyecto Jmeter.jmx` - Main JMeter Test Plan.
* `Csv/` - Input datasets used during execution.
* `Capturas Monitorizacion/` - Monitoring and execution evidence.
* `Informe Final.pdf` - Final report and analysis.
* `Informe Final.docx` - Editable version of the report.
* `informe HTML/` - JMeter generated report.

## Objectives

* Measure response times.
* Evaluate throughput.
* Detect performance bottlenecks.
* Analyze system stability under load.

Detailed results, graphs, metrics and conclusions can be found in the final report included in this repository.
